# CCNA Study Lab

A local study dashboard for Jeremy's IT Lab CCNA course (Days 1-63). Each Day is a full written lesson that explains the material. Every diagram from the course notes appears in the lesson with an explanation. Each Day also has a quiz and links to its Packet Tracer lab and Anki flashcards.

There's no runtime AI and no API key. Lessons are static JSON files in `content/lessons/`, so the app only reads files from disk.

## Setup

Requires Node.js 20+ (tested on Node 24, Windows 11).

```bash
npm install
npm run ingest     # downloads note images to public/notes/ and writes content/manifest.json
npm run dev        # http://localhost:3000
```

On Windows you can instead double-click **`start.bat`**. It runs `npm install`, `npm run ingest`, and `npm run build` only when needed, starts the app, and opens it in Chrome (or your default browser if Chrome isn't installed). Close its window to stop the app.

`npm run ingest` is safe to re-run. It skips images that are already downloaded and retries rate-limited ones.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the app in development mode |
| `npm run build` / `npm start` | Production build and server |
| `npm run ingest` | Parse `content/raw/Course_Notes`, download all images, write `content/manifest.json` |
| `npm run validate` | Check every lesson against the schema. Confirms that each manifest image appears exactly once and that each image file exists |

## Using the app

- **Home:** "Continue where you left off" button, plus a switch-style port panel for Days 1-63. A port's LED turns green once you've opened that Day, and blue for the Day you opened last. Progress is stored in your browser's localStorage.
- **Day page:** the lesson, then Key Terms, Command Reference, Recap, Quiz, and Labs & Flashcards.
- **Keyboard:** ← / → move between Days. When the quiz is on screen, 1-4 picks an answer and Enter / → goes to the next question.
- Click any diagram to zoom.

## Project layout

```
content/
  raw/Course_Notes/      source notes (read-only)
  drive-resources.json   lab + flashcard links per Day
  manifest.json          generated by `npm run ingest`
  lessons/day-NN.json    the written lessons
  lessons/PROGRESS.md    lesson writing log (all 63 done)
  lessons/DECISIONS.md   choices made without review
lib/lesson-schema.ts     Zod schema for lessons
scripts/                 ingest + validate
app/, components/        Next.js App Router UI
public/notes/day-NN/     downloaded images
```

## Lessons

All 63 Days are written and pass `npm run validate`. `content/lessons/PROGRESS.md` records the batches they were written in. If you edit a lesson by hand, run `npm run validate` afterward to check it.

## Note on git

`.gitignore` excludes `content/raw/`, `content/lessons/`, and `public/notes/`, so the notes, images, and written lessons are not committed. To version the lessons, remove `content/lessons/` from `.gitignore`.
